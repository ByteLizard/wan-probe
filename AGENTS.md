# Codex execution guide

Before working in this repository, read [CLAUDE.md](CLAUDE.md) for the shared
repository conventions and execution instructions. Keep those instructions
in that guide as their source of truth.

For Windshift and OpenBao, follow the parent workspace's `AGENTS.md` and its
referenced integration guides. Use the acting agent's own credential identity.

## Agent skills

### Issue tracker

Before ticket work, read `docs/agents/issue-tracker.md`.
Work is tracked in Windshift, Homelab workspace (`HO`).

### Triage labels

Before triage, read `docs/agents/triage-labels.md`.
Use the five standard triage roles.

### Domain docs

Before codebase exploration, read `docs/agents/domain.md`.
Use a single-context glossary and ADR layout.
